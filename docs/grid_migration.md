# 网格迁移分析器

## 背景与证据口径

旧系统对每个坐标做两次 Google polyline 编码：

1. 首次编码精度为 6（下称 p6 原串），只有部分记录还保留。
2. 归档时重新编码为精度 5（下称 p5 旧档），每条记录都有。

两次编码都用 Python 2 式四舍五入（半值远离零），即库内
`polyline._py2_round`：`q_p(x) = sign(x) * floor(|x|*10^p + 0.5)`。

因此解码出的数值只是量化格的中心，不是真值。本分析器只在
`src/grid_migration.py` 中使用 `fractions.Fraction` 精确算术，不依赖浮点。

## 量化可行域（含负坐标半格边界）

整数码 `n`、精度 `p` 对应的真值集合是区间

- `n > 0`：`[(2n-1)/2·10^p, (2n+1)/2·10^p)`，下界含、上界不含；
- `n < 0`：`((2n-1)/2·10^p, (2n+1)/2·10^p]`，靠近零的上界含、远离零的下界不含；
- `n = 0`：两端半值都会远离零舍入，两个端点都不含。

负坐标的开闭方向与正坐标相反，由 `quantization_cell` 直接生成，
端点包含关系随每一次编码的精度（p5/p6）分别处理。

## 逐点判定规则

- 只有 p5 旧档：可行域就是 p5 的两个量化格（纬度、经度各一）。
- 另有 p6 原串：
  - 先做整串核实——把 p6 解码点按 p5 重新编码，判断结果是否逐字节等于
    现存旧档（多点折线按整条字符串比较，含差分编码）；
  - 再做几何核实——p6 量化格与 p5 量化格是否相交。
  - 相交则可行域收窄为两者交集；不相交判定为冲突，原串丢弃，
    可行域保持 p5 旧档不变，冲突原串绝不当作更高精度真值。
- 存在"同点两次编码但整串复现失败、几何仍相容"的真实情形：p6 中心恰好
  落在 p5 半格边界另一侧（见测试
  `test_original_can_fail_reproduction_yet_remain_geometrically_consistent`）。
  两个核实结论分开报告，不互相代替。

## 新格号

目标网格按每轴独立的均匀网格建模：格号
`k = floor((x - origin) / step)`，格体
`[origin + k·step, origin + (k+1)·step)`。可行域与哪些格有非空交集
（含端点开闭判断），这些格就是全部候选：

- 候选恰好一个 → 该点新格号唯一确定；
- 候选多于一个 → 报告全部候选及其依据（可行域区间、证据是否相容/冲突）。

## 使用

真实记录与目标网格规格缺失时无法产出实际逐点表；数据到位后按
`src/migrate_cli.py` 顶部的 JSON schema 提供：

```
.venv/bin/python src/migrate_cli.py records.json
```

内置合成演示（覆盖仅旧档、相容原串、冲突、负坐标半格边界）：

```
.venv/bin/python src/migrate_cli.py --demo
```

所有计算均可在 `tests/test_grid_migration.py` 的 16 个测试中复核，
包括随机 600 点"真值格必在候选中、唯一时必等于真值格"的性质测试。
